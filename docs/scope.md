# Vision-Agentic RAG: Scope & Architecture Design

Ένα προσχέδιο για τη μετάβαση από το κλασικό Text-based RAG (με vector databases και Supabase) σε μια **AI-native νομική μηχανή αναζήτησης με χρήση Multimodal όρασης (Vision)**.

---

## 1. Κατηγορίες Ερωτημάτων & Ανάγκες Χρηστών

Το σύστημα υποστηρίζει δύο διακριτά προφίλ χρηστών, καθένα από τα οποία απαιτεί διαφορετική προσέγγιση αναζήτησης:

### Α. Απλός Χρήστης (Conceptual / Goal-oriented)
*   **Προφίλ:** Πολίτες, επιχειρηματίες, μη-νομικοί.
*   **Ανάγκη:** Αναζήτηση εννοιών ή λύση σε καθημερινά προβλήματα. Η ερώτηση δεν αναφέρει συγκεκριμένο νόμο ή άρθρο.
*   **Παραδείγματα:**
    *   *«Τι άδεια μητρότητας δικαιούμαι πλέον στην εργασία μου;»*
    *   *«Υπάρχει κάποιος νόμος για την Τεχνητή Νοημοσύνη στην Ελλάδα;»*
    *   *«Έχουν αλλάξει οι φορολογικοί συντελεστές για τη μεσαία τάξη το 2025;»*
*   **Τρόπος Επίλυσης:** Εννοιολογική αναζήτηση (Semantic/Keyword Search) πάνω σε **περιλήψεις, τίτλους και tags άρθρων** στα τοπικά ευρετήρια.

### Β. Νομικός / Εμπειρογνώμονας (Source-oriented / Literal)
*   **Προφίλ:** Δικηγόροι, συμβολαιογράφοι, δικαστικοί, νομικοί σύμβουλοι.
*   **Ανάγκη:** Εύρεση συγκεκριμένης διάταξης, έλεγχος ισχύος, τροποποιήσεις. Η ερώτηση περιέχει ακριβή νομικά στοιχεία.
*   **Παραδείγματα:**
    *   *«Τι ορίζει η παρ. 2 του άρθρου 5 του Ν. 5263/2025;»*
    *   *«Έχει τροποποιηθεί το άρθρο 121 του Ν. 5238;»*
    *   *«Ποιο άρθρο καταργεί τις προηγούμενες διατάξεις για την Εγνατία Οδό;»*
*   **Τρόπος Επίλυσης:** **Structured Lookup** απευθείας στα Metadata του ευρετηρίου (Αριθμός Νόμου, Έτος, Αριθμός Άρθρου) για άμεση εύρεση της σωστής σελίδας.

## 2. Αναβάθμιση του Σχήματος Markdown Ευρετηρίων (The Navigation Map)

Για να υποστηρίξουμε και τις δύο κατηγορίες αναζήτησης χωρίς τη χρήση βάσεων δεδομένων, αναβαθμίζουμε τα `.md` αρχεία του `corpus/` ώστε να περιέχουν **Τίτλους, Περιλήψεις και Keywords** ανά άρθρο:

```markdown
---
document_id: 20250100238
law_number: 5263
law_year: 2025
fek: A 238/2025
publication_date: 19.12.2025
title: Ίδρυση Ελληνικού Εργοστασίου Τεχνητής Νοημοσύνης
tags: [τεχνητή νοημοσύνη, συνεποπτεία, ΗΔΥΚΑ, ψηφιακή διακυβέρνηση]
summary: Θεσπίζεται το πλαίσιο ίδρυσης του Εθνικού Εργοστασίου AI και ρυθμίζονται θέματα συνεποπτείας της ΗΔΥΚΑ.
---

# Ευρετήριο ΦΕΚ Α 238

## Χάρτης Πλοήγησης (Navigation Map)

- **Άρθρο 1**: 
  - **Σελίδα**: 1
  - **Τίτλος**: Ίδρυση Ελληνικού Εργοστασίου Τεχνητής Νοημοσύνης
  - **Περίληψη**: Ορισμός της νομικής μορφής, της έδρας και του σκοπού του νέου φορέα AI στην Ελλάδα.
  - **Keywords**: ίδρυση, εργοστάσιο, τεχνητή νοημοσύνη, φορέας, σκοπός

- **Άρθρο 2**: 
  - **Σελίδα**: 1
  - **Τίτλος**: Συνεποπτεία της Η.Δ.Υ.Κ.Α. Μ.Α.Ε.
  - **Περίληψη**: Ρυθμίσεις για την κοινή εποπτεία της ΗΔΥΚΑ από τα Υπουργεία Ψηφιακής Διακυβέρνησης και Υγείας.
  - **Keywords**: ΗΔΥΚΑ, συνεποπτεία, υπουργείο υγείας, ψηφιακή διακυβέρνηση
```

## 3. Σχεδιασμός MCP Tools (Model Context Protocol)

Ο Agent αλληλεπιδρά με το corpus μέσω τεσσάρων (4) εξειδικευμένων εργαλείων, αποφεύγοντας το «διάβασμα» μεγάλων αρχείων κειμένου:

1.  **`search_laws_by_metadata(keywords: list, year: int = None, kind: str = None) -> list[dict]`**
    *   Ψάχνει στα front-matter metadata των `.md` αρχείων για λέξεις-κλειδιά ή tags.
    *   *Επιστρέφει:* Λίστα με candidate ΦΕΚ/Νόμους (π.χ. `[{"document_id": "20250100238", "title": "..."}]`).
2.  **`search_article_in_index(fek_id: str, query: str) -> dict`**
    *   Σκανάρει το συγκεκριμένο ευρετήριο του ΦΕΚ για να εντοπίσει ποιο άρθρο ταιριάζει εννοιολογικά και σε ποια σελίδα βρίσκεται.
    *   *Επιστρέφει:* `{"article": "2", "page": 1}`.
3.  **`get_law_navigation_map(fek_id: str) -> dict`**
    *   Επιστρέφει ολόκληρο τον χάρτη πλοήγησης (δομή άρθρων και σελίδων) ενός ΦΕΚ.
    *   *Χρήση:* Για ερωτήσεις επισκόπησης ή δομής του νόμου.
4.  **`view_pdf_page_as_image(pdf_path: str, page_number: int) -> str (base64)`**
    *   Μετατρέπει τη συγκεκριμένη σελίδα PDF σε εικόνα, επιτρέποντας στο μοντέλο να τη διαβάσει απευθείας.

## 4. Η Ροή της Επαγγελματικής Νομικής Αναζήτησης (Reasoning Loop)

Για μια σύνθετη ή ασαφή ερώτηση φυσικής γλώσσας (π.χ. *«Ποιοι φορείς εποπτεύουν την ΗΔΥΚΑ με βάση τους νόμους του 2025;»*):

```text
[Ερώτηση Χρήστη] 
       │
       ▼
[1. Intent Extraction] ──► Εξαγωγή φίλτρων: keywords=["ΗΔΥΚΑ", "εποπτεία"], year=2025
       │
       ▼
[2. Metadata Search] ────► Κλήση search_laws_by_metadata()
       │                   └─► Επιστρέφει: Ν. 5263 (ΦΕΚ Α 238/2025)
       │
       ▼
[3. Index Lookup] ───────► Κλήση search_article_in_index(fek_id="20250100238", query="εποπτεία ΗΔΥΚΑ")
       │                   └─► Επιστρέφει: Άρθρο 2, Σελίδα 1 (λόγω τίτλου "Συνεποπτεία της ΗΔΥΚΑ")
       │
       ▼
[4. Vision Reading] ─────► Κλήση view_pdf_page_as_image(pdf="20250100238.pdf", page=1)
       │                   └─► Μετατροπή σε base64 & αποστολή στο Multimodal LLM (Gemini 2.5)
       │
       ▼
[5. Synthesis] ──────────► Παραγωγή 100% ακριβούς απάντησης με νομικές παραπομπές:
                           «Σύμφωνα με το Άρθρο 2 (σελίδα 1) του Ν. 5263/2025 (ΦΕΚ Α 238/2025)...»
```

---

## 5. Οφέλη & Πλεονεκτήματα της Αρχιτεκτονικής

*   **100% Ακρίβεια (Deterministic Routing):** Η εύρεση της σελίδας γίνεται μέσω του δομημένου Markdown Navigation Map, εξαλείφοντας την τυχαιότητα του naive Vector Search.
*   **Προστασία από Hallucinations:** Ο Agent απαντά **μόνο** όταν «δει» με τα μάτια του την εικόνα της σελίδας του PDF.
*   **Ταχύτητα & Οικονομία:** Η αναζήτηση στα ελαφριά Markdown ευρετήρια (μερικών KB) είναι ακαριαία, εξοικονομώντας context window και API κόστη.
